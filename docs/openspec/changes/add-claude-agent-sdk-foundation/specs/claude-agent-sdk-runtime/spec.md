## Purpose

为桌面工作台提供基于 Claude Agent SDK 的结构化会话运行能力，使本地服务可以直接获得会话生命周期与消息事件，而不是依赖终端字节流或事后解析会话日志。

## ADDED Requirements

### Requirement: SDK 运行时可用性探测

本地服务 SHALL 提供运行时健康检查，返回 SDK 是否可加载、SDK 版本、实际使用的 Claude Code 运行时路径以及当前 Node 运行时版本。SDK 不可加载或运行时缺失时，检查 SHALL 返回不可用状态与可读的错误原因，且不得影响现有终端会话与工作区接口。

#### Scenario: 运行时可用

- **WHEN** 客户端请求 SDK 健康检查，且依赖与 Claude Code 运行时均可用
- **THEN** 服务返回可用状态、SDK 版本、运行时路径与 Node 版本

#### Scenario: 运行时不可用

- **WHEN** SDK 依赖缺失或 Claude Code 运行时无法定位
- **THEN** 服务返回不可用状态与具体原因，服务进程保持运行，现有终端会话接口仍可正常使用

### Requirement: 结构化会话生命周期

本地服务 SHALL 支持通过独立接口创建 SDK 会话，并接受项目路径、可选初始提示词、可选模型与权限模式。创建成功后 SHALL 返回会话标识、会话所属项目与连接事件流所需的信息。项目路径 SHALL 限定在已登记工作区项目范围内。

#### Scenario: 创建会话成功

- **WHEN** 客户端提交有效的项目路径与初始提示词
- **THEN** 服务创建 SDK 会话并返回会话标识与事件流连接地址

#### Scenario: 拒绝无效项目路径

- **WHEN** 客户端提交未登记或越界的项目路径
- **THEN** 服务拒绝创建并返回明确错误，不启动任何 SDK 运行时进程

### Requirement: 会话事件流

服务 SHALL 通过 WebSocket 向订阅客户端推送结构化会话事件，事件至少覆盖系统初始化、助手消息、工具调用、工具结果、最终结果与错误。事件 SHALL 保留会话标识，供客户端关联到具体会话。单个客户端断开 SHALL NOT 影响其他订阅者或会话本身。

#### Scenario: 订阅并接收事件

- **WHEN** 客户端连接会话事件流并发送提示词
- **THEN** 客户端依次收到系统初始化、助手消息与最终结果事件，且每条事件携带会话标识

#### Scenario: 客户端断开重连

- **WHEN** 订阅客户端断开后重新连接同一会话
- **THEN** 会话继续运行，新连接可以继续接收后续事件

#### Scenario: 会话启动后订阅

- **WHEN** 客户端在会话已启动后连接事件流
- **THEN** 客户端先收到最近事件回放，其中至少包含系统初始化事件，随后接收新产生的事件

### Requirement: 会话中断与关闭

服务 SHALL 支持中断正在运行的 SDK 会话，并支持在结束后关闭会话、释放运行时进程。中断后 SHALL 通知订阅客户端会话已中断，并保留会话记录供再次查看。

#### Scenario: 中断运行中的会话

- **WHEN** 客户端对运行中的会话发起中断
- **THEN** 会话停止继续产生助手输出，订阅客户端收到中断事件，会话进程被终止

#### Scenario: 关闭已结束的会话

- **WHEN** 客户端关闭已结束的会话
- **THEN** 服务释放该会话的运行时资源，后续对该会话的事件订阅被拒绝

### Requirement: 本地配置与渠道注入

SDK 会话 SHALL 沿用现有本地 Claude 配置来源（用户级、项目级与本地项目设置），并 SHALL 把当前激活渠道的连接地址、凭据与模型变量注入会话运行时环境。注入 SHALL 仅作用于该 SDK 会话，不得改写全局 `~/.claude/settings.json`。

#### Scenario: 使用当前渠道运行

- **WHEN** 用户存在激活渠道并创建 SDK 会话
- **THEN** 该会话运行时环境包含当前渠道的连接地址、凭据与模型变量，全局设置文件内容保持不变

#### Scenario: 无自定义渠道

- **WHEN** 用户没有配置自定义渠道
- **THEN** 会话使用本地默认 Claude 配置运行，不产生额外的环境覆盖

### Requirement: 双模式隔离与兼容

SDK 会话与现有终端会话 SHALL 独立管理，互不影响。现有工作区、终端、配置管理与渠道接口的请求与响应行为 SHALL 保持不变；SDK 能力故障 SHALL NOT 阻断终端会话的创建、连接与中断。

#### Scenario: 终端会话不受影响

- **WHEN** SDK 运行时不可用或 SDK 会话异常退出
- **THEN** 现有终端会话仍可正常创建、连接、输入与中断

#### Scenario: 会话记录隔离

- **WHEN** 用户同时存在终端会话与 SDK 会话
- **THEN** 两类会话分别记录与展示各自的标识、项目归属与状态，互不覆盖
